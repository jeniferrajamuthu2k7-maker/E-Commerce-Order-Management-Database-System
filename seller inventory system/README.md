Seller & Inventory Management System

A MySQL-based inventory management system designed to manage seller information, product inventory, stock levels, pricing, and availability. The project includes data insertion, updates, and SQL reports to analyze stock status, out-of-stock products, seller portfolios, and inventory valuation.

This project successfully demonstrates the use of MySQL for seller and inventory management. Through INSERT, UPDATE, JOIN, and aggregation operations, the system provides useful insights into stock availability, product status, seller performance, and inventory valuation, supporting better inventory management and decision-making.
