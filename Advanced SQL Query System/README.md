# Advanced SQL Query System

## 📌 Project Overview

This project uses advanced SQL queries and subqueries to analyze e-commerce data, including product prices, customer spending, and sales performance.

## 🎯 Objectives

* Identify premium products and high-value customers.
* Analyze best-selling products and category revenue.
* Practice nested, single-row, multi-row, and correlated subqueries.
* Generate reports for business decision-making.

## 🛠️ Technologies Used

* SQL
* MySQL
* E-Commerce Database

## 🗂️ Database Tables

* `customers`
* `products`
* `categories`
* `orders`
* `order_details`
