Customer Order Management

This project contains SQL queries for managing customer orders and generating useful order reports. It connects the Customers, Orders, Order_Details, and Products tables.


Important SQL Concepts Used

SELECT – Displays order and customer details.
INSERT – Adds customer, order, and product details.
JOIN – Connects related tables.
COUNT() – Counts the number of orders.
SUM() – Calculates total sales and quantity sold.
AVG() – Finds the average order value.
GROUP BY – Groups records for analysis.
ORDER BY – Sorts the report results.
UPDATE – Modifies order status and quantity.
